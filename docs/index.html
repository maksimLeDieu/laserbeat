Musique ML

Le lecteur de musique des salles de laser game

Windows Windows 10 et 11 Mac macOS 11 ou plus récent

Dernière version

Installer sur Windows
  1. Ouvrez le fichier téléchargé LaserBeat-Setup.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Cliquez sur Suivant puis Installer. Musique ML apparaît sur le Bureau et dans le menu Démarrer.

Ensuite, Musique ML se met à jour tout seul. Déjà installé ? Le nouvel installateur garde les réglages, favoris et morceaux ajoutés.

Installer sur Mac
  1. Ouvrez le fichier téléchargé Musique-ML-Mac.dmg, puis glissez Musique ML sur le dossier Applications.
  2. Ouvrez l'app Terminal (dans Applications › Utilitaires), collez cette ligne puis appuyez sur Entrée :
    xattr -dr com.apple.quarantine "/Applications/Musique ML.app"
    Elle retire seulement l'étiquette « téléchargé depuis Internet » qui empêche macOS d'ouvrir l'appli.
  3. Ouvrez Musique ML depuis le dossier Applications. C'est fait, les fois suivantes aussi.

Autre méthode, sans Terminal : ouvrez Musique ML, cliquez sur Terminé, puis Réglages Système › Confidentialité et sécurité › Ouvrir quand même.

Mises à jour : Musique ML vous prévient quand une nouvelle version existe. Téléchargez-la ici, glissez-la dans Applications pour remplacer l'ancienne, puis refaites l'étape 2. Réglages et favoris sont gardés.
