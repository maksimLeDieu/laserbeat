Musique ML

Le lecteur de musique des salles de laser game

Télécharger pour Windows

Dernière version · Windows 10 et 11 (64 bits)

Installer

  1. Ouvrez le fichier téléchargé LaserBeat-Setup.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Cliquez sur Suivant puis Installer. Musique ML apparaît sur le Bureau et dans le menu Démarrer.

Ensuite, Musique ML se met à jour tout seul. Déjà installé ? Le nouvel installateur garde les réglages, favoris et morceaux ajoutés.
